# Design, history and proposals

Start with [`../README.md`](../README.md) for current code and commands, and
[`../COGNITIVE_ARCHITECTURE.md`](../COGNITIVE_ARCHITECTURE.md) for implemented
cognition. Latest evidence is linked from the agent entry guide, not inferred
from the age or ambition of a design document.

- `design/`: retained substrate, worldbuilding, God, mapping and office specs.
  These explain design intent; not every described mechanism is active.
- `history/`: older architecture/roadmap/context and dated attention, H3 and
  Project89 demonstration work. Retained for provenance, not current task orders.
- `proposals/`: possible future applications, including the living headquarters.
- `reference/`: historical library reference material; verify against installed
  dependencies before relying on its API examples.

The normative World Graph / Change Record design remains [`../../CANON.md`](../../CANON.md).
Implementation records and test evidence remain alongside their owners under
`src/architecture`, `src/cognition`, `src/demo` and `src/evals`; their checkpoints
explicitly distinguish passing regressions from open live behavioral gates.
