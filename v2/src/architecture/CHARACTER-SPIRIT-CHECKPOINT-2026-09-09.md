## Implemented: authored character past and identity

`CharacterPast` is strict creation-time data: private background, 1–6 drives,
and 1–6 formative memories. Each memory carries recollection, remembered life
period, emotional tone, significance, self-belief, meaning and recall cues.
Provenance distinguishes authored history, uncertain recollection and implanted
history. Provenance is author-visible, not automatically NPC self-knowledge.

Library agent configuration and God's create-agent tool accept `past`. God's
authoring instructions request formative history, ordinary warmth as well as
difficulty, and consistency with the setting. Drives seed existing aspirations.
Background stays in the private persona; public appearance is not a biography.
People or places mentioned in memories are not automatically created in the
current world. This does not validate an entire cast's mutually consistent
biographies automatically.

Formative memories are append-only `NarrativeEntry` entities linked by
`HasNarrative`; `identityJson` adds interpretation/provenance to that same
archive. Creation validates the whole input before allocating a new actor.
Reseeding a life is rejected. No fake public events, completed actions, plans or
goals are manufactured from backstory.

Foreground context, autonomous goals, appraisal and background reflection use
bounded relevant identity recall. Ordinary thoughts do not bury anchors;
pagination also prevents hundreds of revisions to one anchor from evicting a
different childhood memory. Relevant recall presents at most three anchors.

The existing reflection system can form a new anchor or revise its meaning only
from sufficiently significant self-insight citing issued, owner-bound experience.
Revisions cite the current anchor plus experience; reflection-on-reflection is
not enough. A revision appends history rather than rewriting the original
memory. Replayed/ungranted/late results cannot mint identity changes. Current
meaning changes invalidate pending consumers whose context depended on it.

Authored seeds are available even when `narrativeMind` is false, without enabling
inference. Runtime formation/revision requires the existing `narrativeMind`
mode. Default model/controller selections were not changed. Generated managed
place/entity blueprints do not yet expose the optional `past` authoring field;
their actors retain canonical cognition but are not automatically given rich
formative biographies through that path.
