# Receipt-driven intention reconsideration

Opt-in: `createSimulation({ ..., experienceReconsideration: true })`.
The normal priority controller remains in use. This experiment does not enable
the separate situated controller or change notification salience. Select this
runtime option again when loading a saved world; goal changes and memories are
ordinary persistent ECS data, not a restored permission to execute old work.

## Mechanism

The existing private appraisal of an actually experienced receipt may now return
`intentionRevisions`, at most three edits to a bounded catalog of the actor's
own personal intentions. Each edit either:

- `reprioritize`: sets priority 1–10 and records a private reason; or
- `release`: retires the intention and its pending plan, without success credit.

Both active and paused subjective/exploratory intentions are eligible, but only
when generated by the foreground, autonomous cognition or explicit personal-
desire authoring. Assigned goals, schedules, communication notification goals,
physical success contracts, other actors' intentions and terminal goals cannot
be edited. Definitions and progress are never rewritten. Reprioritizing retires
the old executable plan so a changed purpose is not followed by obsolete work.

The existing optional `goalUpdate` can introduce a different enduring purpose.
A release plus replacement preserves the old strategy as history rather than
mutating its identity. The model is asked to distinguish the concern from one
blocked strategy, not to choose any specific emotional display or recipient.
There are no breakup-, character-, message-content- or phone-specific rules in
the reconsideration mechanism. Ordinary events may leave every goal unchanged.

It is the **same single appraisal call**, with the same model, 700-token output
ceiling, four-second timeout and retry/backoff behavior. It does not introduce
a second serial planner. Foreground and existing background cognition remain
unchanged. Enabling this option does not automatically wire every sensory event
to appraisal: the current production receipt producer is the sitcom's completed
phone read. Other producers must supply actual, actor-owned experienced receipts
through `queueExperiencedEvent`; narration or unread messages are not receipts.

## Admission and execution

The exact receipt batch, source, actor, persona, affect and owned goals are
checked around inference. Reconsideration also checks the exact definitions,
identity, ownership, eligibility, priority, progress and deferral state of every
edited goal. Invalid/duplicate/foreign edits reject the whole appraisal before
feelings, new goals or memory are committed. Changes of the runtime option also
invalidate an in-flight appraisal. Every preparation runs before synchronous
commits; a newly created independent intention does not invalidate the batch.

Revisions are recorded in the actor's private episodic memory. Operator
diagnostics expose only IDs, dispositions and new priorities, not private
reasons. Existing stale-action guards react to priority/status changes. An
already started physical act still has its real duration and actual outcome;
reconsideration cannot undo it or make a new plan step happen retroactively.

## Evaluation

Compare `--reconsideration=on` with `--reconsideration=off`, using
`--controller=priority` for both in `sitcom-breakup-check.ts`. Two matched
120-second breakup pairs and one matched neutral-message pair use the same
two operator stimuli at 8s/28s, unchanged model/limits, starting memories,
physics and other systems. Retain failures and identical source fingerprints.

Review actual edits, goals and thoughts against completed physical/social
events. Success is coherent sustained reorientation, not a compulsory disclosure.
Neutral messages should not manufacture dramatic personal crises. Report
read/reply latency, appraisal latency/failures, completed hearing, repetition,
invalidated actions and foreground tasks. More schemas passing is not itself
evidence that the episode improved. No H3 or narrator interventions are used.
