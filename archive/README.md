# Historical implementations

These folders preserve earlier Argos experiments. They are **not** alternative
entry points for the current engine, and their old instructions, model claims
and acceptance results do not describe today's runtime.

- `argos-v1/`: former root `src`, package/config files and 2024–2025 design notes.
- `LSE/`: earlier linguistic simulation engine and design references.
- `god-agent-v2/`: separate historical God-agent prototype; not the active
  `v2/src/god` implementation.
- `designDocsBackup/`: historical design material, retained rather than deleted.

Current code is in [`../v2`](../v2/README.md); start with [`../AGENTS.md`](../AGENTS.md).
The independent behavior-tree research project is now in
[`../research/psyche-bt`](../research/psyche-bt/README.md), not retired here.

Original paths in quoted historical documents and old evaluation logs describe
their original checkout. Relocation does not make their old run commands current.
Restore an older Git revision or deliberately adapt the archived project's local
configuration if you need to reproduce an old experiment. Do not run archived
providers or install their dependencies as part of current-engine setup.

Local generated logs/scratch files were moved into the ignored
`v2/recordings/repository-scratch-20260927/` folder. No failed evidence was erased
by this archival move. These private artifacts are not part of a fresh clone.
